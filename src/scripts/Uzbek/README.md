# Uzbek language support in AeonVoice

This code implements text processing rules for the Uzbek language. It was created as part of the work on Sevinch, the first Uzbek voice for AeonVoice.

This repository contains the sourse code. You can find the compiled version [here](https://github.com/AeonVoice/Uzbek-bin).
