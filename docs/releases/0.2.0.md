# AeonVoice 0.2.0

Released: 2026-09-22

## Highlights

- `AeonVoice` can now be consumed as a normal NuGet package on Linux without
  application-specific native-library loading or custom asset-copy targets.
- `AeonVoice.Native` packages Linux runtime assets under the standard NuGet
  `runtimes/<RID>/native` layout for `linux-x64` and `linux-arm64`.
- The bundled English, Leena, configuration, and dictionary assets are copied
  to `AppContext.BaseDirectory/aeonvoice/` through the package's
  `buildTransitive` target.
- Added a packaged-consumer smoke test for both Linux RIDs. It restores only
  `AeonVoice` from the packed artifacts, synthesizes with Leena, and verifies
  that a non-empty PCM WAV file can be written.
- The managed API now includes WAV-writing convenience support through
  `SynthesisResult.WriteWave`.

## Upgrade

Update the managed package; `AeonVoice.Native` remains a transitive dependency:

```bash
dotnet add package AeonVoice --version 0.2.0
```

No source changes are required for existing consumers. Applications should use
the default `AeonVoiceEngine` resource paths; bundled resources are provided at
runtime under `aeonvoice/` next to the application.

## Verification

The release workflow builds and tests both `linux-x64` and `linux-arm64` before
publishing either NuGet package.
